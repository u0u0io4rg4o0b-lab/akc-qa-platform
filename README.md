# AKC QA Platform

**把需求、實際測試與原始證據放在一起的個人 QA 工具。**

下載這個資料夾，用能讀寫本機檔案、執行終端命令的 Agent 開啟，告訴它你想測哪個自己的專案即可。工具本身不用 API key、不安裝第三方套件。模型服務、受測專案及其依賴由使用者自行準備。

> 公開預覽版 `0.4.0-preview.1`。僅限個人、非商業用途；禁止營利、付費 QA、公司內部營運或代營運。這是 **source-available（公開原始碼）**，不是 OSI 定義的開源授權。見 [LICENSE](LICENSE)。

## 開始

在 Codex、Claude Code 或其他具有本機工具能力的 Agent 中開啟本資料夾，直接說：

> 請讀取 START_HERE.md，先確認這套工具能啟動，再依我的專案實況規劃並執行 QA。我的目標專案是「填入路徑」，我想確認「填入功能」。先用本機合成資料，保留失敗、未測項目與原始證據。

也可先在本資料夾的終端機執行：

```sh
python3 qa.py doctor
python3 qa.py demo
```

需要 **Python 3.11 以上**。Windows 使用 `py -3 qa.py doctor` 與 `py -3 qa.py demo`。如果 `python3` 指向舊版本，請由 Agent 找到已安裝且符合版本的 Python；缺少時提供安裝方式，由你決定安裝。工具不會自行下載。

`demo` 真的執行包內折扣程式的五項檢查，並印出結果報告位置。範例通過只表示工具與此範例可運作。接著依 [START_HERE.md](START_HERE.md) 測自己的專案。

## 能交付什麼

- 與需求、指定來源檔、測具、命令及執行環境綁定的計畫。
- 真實程序的退出碼、開始／結束、stdout／stderr、逾時與未執行項。
- JSON 完整等值判讀，或明確標示僅核對退出碼；不是看到 `PASS` 字樣就通過。
- 可攜證據資料夾及繁中報告，可在其他路徑用 `verify` 離線重新核對。

每次結果使用新目錄，失敗後停止後續檢查，修復後建立新計畫與新結果。依變更影響選擇必要檢查；本版沒有自動推導依賴或沿用舊證據的功能。

## 使用範圍

命令直接以你的使用者權限執行，適用**你信任且已授權執行的個人本機專案**。沒有檔案、網路或憑證隔離；子命令可能連網、讀憑證、修改資料或執行 package hooks。不要用來執行陌生下載物。雲端模型可能接收你交給它的內容，本機工具沒有 API key 不表示 Agent 全程離線。

本版支援命令列檢查與測具接入。瀏覽器、資料庫、雲端、遠端掃描、真實帳號及付款不會因為下載就具備或取得授權；需要相應工具、環境與驗收。只有文字對話能力、無本機工具的模型可以協助規劃，無法自行執行這套程式。沒有保證任何模型一定完成任何 QA。
