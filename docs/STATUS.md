# 版本與證據範圍

版本：`0.4.0-preview.1`，個人非商業公開試用版。

可用：本機計畫、直接命令執行、JSON 判讀、命令退出狀態、原始輸出、報告與離線核對。只使用 Python 3.11+ 標準函式庫。原始版本歷史與私人收據不包含在此公開包。

發布驗證的精確環境、次數及結果見 [RELEASE_VALIDATION.json](RELEASE_VALIDATION.json)。工具自測與五項樣例分開計數，樣例不是朋友專案的 QA。該檔只記錄發布前實際完成的觀察，不是 CI 執行或跨機器成功的保證。

| 範圍 | 狀態／界線 |
|---|---|
| 個人可信本機命令 | 已實作；啟動與核對結果依發布驗證記錄 |
| Codex／Claude 入口 | 文件已提供；Claude 與朋友全新電腦的實際操作尚未驗收 |
| Windows／Linux | 程式含平台處理；本次原生執行是否完成見發布驗證，不預設已通過 |
| 瀏覽器／DB／遠端 API | 無內建整合；可由另行準備的測具觀察，結論依實際環境 |
| 隔離 runner／封網／獨立證據保管 | 不提供 |
| 安全審計／正式產品驗收 | 未完成，不能由工具自測升格 |
| 自動影響分析／自動回歸沿用 | 不提供；Agent 應根據實際變更規劃並說明理由 |

下一個產品 Gate 是朋友在自己的電腦，以其自選 Agent 對一個自己的個人專案完成需求 → 計畫 → 真測試 → 報告 → 失敗讀回，收集實際相容性及易用性問題。發布不等待建立託管平台或重做無關歷史測試。
