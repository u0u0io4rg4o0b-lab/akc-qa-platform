## 反向檢查與版本相容

不能只修一行就改稱跨平台全部通過。新版報告新增原始輸出摘要後，也必須防止輸出中的 HTML／表格／控制字元改寫報告；摘要會跳脫顯示，原始 bytes 保留。原因碼、退出碼、預覽與結果人口都重新核對，不能只把 manifest 重算就取得假綠。

升版亦不能使既有證據無法核對。preview.2 支援讀回 preview.1 的原 schema 與原報告；舊版僅允許已知 LF／CRLF 的完全相同內容，先核對原 manifest。新版仍固定 LF。舊計畫要重建才能執行，避免把不同工具來源混成一輪。新版原因、預覽及覆蓋欄位有新 schema，未假冒舊版輸出。

## 必要研究與近三個月時效

本輪時效窗口為 **2026-08-08 至 2026-11-08**；優先採近兩個月。查詢／抓取日不等於發表或更新日，新的文章也不自動勝過適用版本的實測。不為追求新日期，把穩定依賴換成未發行 main 或把 Python 3.15 的預設編碼套到朋友的 3.11。

1. **Python 3.11 的文字／位元組換行與標準流編碼。** [3.11 io 文件](https://docs.python.org/3.11/library/io.html)與 [sys 文件](https://docs.python.org/3.11/library/sys.html)頁尾更新為 2026-10-26；[3.11.18 發行頁](https://www.python.org/downloads/release/python-31118/)為 2026-10-25。現行規則支持用二進位寫固定報告 bytes 與重新設定 CLI 標準流；本輪控制重現與回歸提供 11/8 的新證據。沒有要求朋友先換 Python 才避開工具缺陷。
2. **Windows 程序啟動、逾時與清理的實際保證。** [Python 3.11 subprocess 文件](https://docs.python.org/3.11/library/subprocess.html)更新為 2026-10-26，支持 creationflags 及直接子程序終止的適用邊界。本輪僅採用 console flag；完整子孫程序管理沒有足夠本輪證據，所以不宣稱已修好。查到的 Microsoft process-creation-flags 頁更新於 2025-07-14，未列入近三個月主證分母，也不把最近抓取當成新研究。
3. **案例判讀、舊證據相容與跨平台驗收。** 判準來自本次需求、既有契約、11/8 新重現與負控；不依賴一般 Agent 排名文章。[GitHub 官方 Python CI 說明](https://docs.github.com/en/actions/tutorials/build-and-test-code/python)作操作參考，頁面更新日未知，不充當符合時效的已發表研究。實際平台、Python、原版失敗／新版結果及精確來源由本次 CI 收據決定，不能以 YAML 存在代替成功。

Node 警告處置只補有界操作指引。[官方 CLI 文件](https://nodejs.org/api/cli.html#--disable-warningcode-or-type)支持選定 warning code/type，該頁本輪沒有可核更新日，不計近三個月主證。11/8 在本機 Node v26.0.0 真執行三個新控制：預設警告存在、具名 ExperimentalWarning 可停用、其他錯誤仍保留 stderr 與退出碼 1。這是新量測，沒有宣稱本機 Node 是最新版；朋友沒有提供 Node 版本，故仍需在其版本確認。核心不依賴 Node，也不默默加任何隱藏警告參數。

CI 使用當下可解析的官方固定 tag SHA。setup-python v7.1.0 發行日期為 2026-10-22，符合窗口；checkout v7.0.1 為 2026-07-20，雖是當下最新穩定發行，也不算近三個月研究主證。保留其精確來源作既有工具依賴，經本次實跑再判斷，不為補日期選未發布程式。沒有把過時來源當成新的 Agent 能力證明。

## 尚缺資料與下一個 Gate

本輪換行、編碼及報告修正不需要等待額外大規模研究。以下只有在要擴大相應承諾時才是必要差額：

- **Windows 完整程序樹／Job Object 清理**：需近三個月可核來源，並測父程序先退出、孫程序持有 pipe、逾時、取消、啟動失敗、既有 Job 限制及清理讀回；目前不得從 PARENT_ONLY 升格。
- **測試套件逐案人口接頭**：需使用者選定 reporter／格式／版本及去敏原件，才設計穩定 ID、跳過、失敗、零案例與重複案例的 parser；沒有輸出契約前不做泛用字串計數。
- **朋友忙碌 Windows 11 與新版 Claude Code 回測**：需新版原生輸出及失敗分類才能釐清原 145 秒那輪，或證明新版已改善其實際體驗。可用新版套件回測，不需要密碼、金鑰或私人專案內容。

這些差額各自有證據範圍，不把全部研究都列為本輪發布的前置，也不因新測試數量而擴大安全或產品驗收結論。精確結果見 [RELEASE_VALIDATION.json](RELEASE_VALIDATION.json)；舊版 20/20 與歷史收據問題仍保留在原提交。
