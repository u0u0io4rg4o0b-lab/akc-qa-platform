# 後續使用與自願回饋

本輪工作是修正公開授權、文件與 GitHub 內容。**不要求維護者另交一個具名商業試點，也不要求下載者提供專案或回饋，才能使用這套工具。** 2026-11-08 PM 後續澄清確認此範圍；Gate E 指後續累積實際使用與回饋，不是這次發布的額外前置條件。既有專案的開發、測試及啟動驗證依原本進度續行。

個人、開發者、企業可依 LICENSE 2.0 自行下載，使用有本機檔案與終端能力的 Agent 測試其有合法權利的商業或非商業專案。獨立營利 QA 服務與 QA 平台再商業化仍需另授權；一般產品測試不需要先向維護者申請個別許可。

願意回饋時，以下資訊有助於重現與選擇下一個修正：

- 作業系統、Python／Agent 版本、AKC 提交或授權標籤，以及啟動、操作或整合時遇到的問題。
- 預期行為、實際結果與可分享的最小重現：缺陷、誤判、看不懂的失敗原因、報告遺漏或未驗證範圍。
- 是否對自己的工作有幫助、哪一步增加負擔，以及相較既有流程有何具體差異；沒有可比條件就不推算省時百分比。

可透過本儲存庫 Issues 提供一般問題；敏感問題依 [SECURITY.md](../SECURITY.md) 處理。不要上傳原始憑證、個資、私密專案或完整未脫敏證據；可以只提供合成／脫敏重現。這不是授權維護者主動聯絡、登入、測試第三方系統或公開他人的資料。

維護者自身使用、工具自測、其他開發者回饋、獨立安全審計與市場價值，各自有其證據範圍。本輪不因沒有新增外部回報而否定既有使用經驗，也不將工具自測或個人經驗自動推廣為所有人的使用價值。後續按實際問題與可核證據修正，沒有回報的部分維持未知。
